# Table descriptions

## Main Table 1

Summarizes the datasets, independent-unit counts, platforms, analytic roles,
outcomes, and current score coverage used in the revision.

## Main Table 2

Reports all coefficients from the common-roster M1-M4 Cox models. The estimates
are same-cohort, apparent, post-selection associations rather than external
validation.

## Supplementary Table 1

Lists all 539 historical Yellow-module symbols, their availability in the
locked modelling feature set, and their conditional selection-frequency
descriptors.

## Supplementary Table 2

Provides the complete sparse4 definition, coefficients, TCGA training means and
standard deviations, external weights, tuning parameters, and evidence-status
labels.

## Supplementary Table 3

Contains participant-level TCGA sparse4 values and is not redistributed in this
public code repository. The manuscript supplement remains the controlled
delivery location.

## Supplementary Table 4

Contains participant-level GSE159067 partial-score values and is not
redistributed here. It documents an exploratory two-of-four-gene evaluation,
not complete-model validation.

## Supplementary Table 5

Reports gene-level unsigned virtual-perturbation distances and adjusted
probabilities. Directional expression or causal regulation cannot be inferred
from these distances.

## Supplementary Table 6

Summarizes prespecified quantile-based LymphHot cutpoint sensitivities. These
cohort-dependent comparisons do not define an optimized clinical threshold.

## Supplementary Table 7

Defines TLS10/TLS9 and the complete Yellow spatial feature map, then reports the
patient-level primary spatial inference. Participant- and section-level source
ledgers are not redistributed here.

## Supplementary Table 8

Lists coefficients and conditional selection frequencies for the separate
lambda-min procedure whose full-data fit retained 64 genes. This procedure is
not the sparse4 model.

## Supplementary Table 9

Distinguishes conditional internal-validation estimands for sparse4 and the
separate lambda-min procedure, including their proper inferential boundaries.

## Supplementary Table 10

Reports TCGA model-comparison metrics for continuous CD79A, IKZF1, their
combination, and the exploratory LymphHot indicator, including formal
likelihood-ratio tests in the companion 10b output.

## Supplementary Table 11

Reports post hoc external LymphHot evaluations, group counts, survival
estimates, and multiplicity fields. Both cohorts are interpreted as negative
external applications rather than proof of equivalence.

## Supplementary Table 12

Reports sparse4 coverage, hazard ratios, discrimination, uncertainty, and PH
diagnostics in two FULL and one PARTIAL external cohort.

## Supplementary Table 13

Documents hypoxia-signature coverage, score correlations, augmented M4
coefficients, likelihood-ratio comparisons, and PH diagnostics.

## Supplementary Table 14

Reports non-bootstrap uncertainty for the conditional fixed-OOF C-index and
patient-level spatial effects. Individual delete-one-unit ledgers are not
redistributed.

## Supplementary Table 15

Describes complete-case selection through variable-specific missingness,
standardized differences, and follow-up summaries without treating arithmetic
event differences as proof of a missingness mechanism.

## Supplementary Table 16

Provides the B-state marker contract, aggregate marker-detection summaries,
reference-label confusion, and object scope. State labels remain provisional
where reference agreement is weak.

## Supplementary Table 17

Defines every project expression signature by ordered gene, weight, and role,
including explicit distinction from measured immune-cell fractions.

## Supplementary Table 18

Records external gene coverage, endpoint definitions, FULL-score multiplicity,
and LymphHot results. Participant-level external ledgers are not redistributed.

## Supplementary Table 19

Collects method-robustness diagnostics for HPV, WGCNA, clustering,
nonlinearity, multiplicity, and stage-imputation feasibility.

## Supplementary Table 20

Reports platform, signature, external-direction, heterogeneity, fraction
availability, and composition-adjusted spatial sensitivities at aggregate
levels.
